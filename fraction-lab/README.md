# Jackson’s Fraction Lab

Open `index.html` in any modern browser. No build or installation needed. For offline use, the optional web fonts fall back to system fonts. Progress lives in this browser’s local storage; private browsing or clearing site data can remove it. No account or server is needed for local use.

## Coverage: 20 topics

- Fractions (6): addition and subtraction with like/unlike denominators; fraction × fraction; fraction ÷ fraction.
- Mixed numbers (10): addition and subtraction, each with like/unlike denominators and with/without regrouping (8); multiplication; division (2).
- Fraction and whole numbers (4): fraction ÷ whole, whole ÷ fraction, fraction × whole, whole × fraction.

Addition regrouping means fraction parts sum to at least one whole, including exactly one. Subtraction regrouping means borrowing a whole because the first fraction part is smaller. Denominator classification refers to the displayed operands. Problems use positive proper fraction parts, denominators 2–12, and nonnegative subtraction results.

Answers may be unsimplified or improper fractions, mixed numbers, integers, or exact decimals (up to six decimal places). Rounded repeating decimals are not exact; use a fraction. Invalid entries do not affect progress. First valid submission counts toward first-try accuracy; solving later still earns a solved problem. Skipping does not count as an attempt. Hints can be shown step by step through the final answer. Each skill has a five-solved practice goal; this is a practice count, not a mastery assessment. Mix mode samples all 20 topics.

Run `node test.cjs` to validate generated topic constraints and rational arithmetic.
